# Security

FileShed is file-hosting software; if you find a vulnerability, we want to hear about it privately first.

## Reporting a vulnerability

Email **developers@fileshed.app**, or use GitHub's private vulnerability reporting on this repository. Include
enough detail to reproduce: the version, the deployment shape (SQLite or Postgres, reverse proxy), and steps.

You will get an acknowledgement within seven days. We will work with you on a fix and coordinate disclosure;
please do not publish details until a fixed release is available.

## Supported versions

FileShed is pre-1.0. Fixes land in the latest release only; upgrade to the newest version before reporting, if
you can.

## Credit

Reporters are credited in the release notes for the fix, unless you ask otherwise.
