# CLA signatures

Contributor signatures for FileShed, recorded by the CLA Assistant workflow that lives on `main`.

When a contributor signs on a pull request, the bot commits their signature to `signatures/version1/cla.json` on this
branch. That file is written entirely by the action — do not create or edit it by hand, and do not protect this
branch, or the bot loses its ability to record a signature.

The agreement itself is [`.github/CLA.md` on `main`](https://github.com/fileshed/fileshed/blob/main/.github/CLA.md).
